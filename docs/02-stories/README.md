# Stories

Stories are the unit of implementation for OpenCode.

Filename convention:

```text
<ID>-<short-slug>.md
```

Examples:

```text
VET-004-clinical-encounter.md
CAL-001-create-appointment.md
INV-004-transfer-stock.md
```

Use `../_templates/STORY.md`.

A Story may not change PRD scope without an accepted Decision.
